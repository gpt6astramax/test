# 景深翻页 · 设计总结

音乐库 App 的 UI 原型。这份文档记录它的设计语言和所有可调参数，写正式版时照着搬。

## 1. 一句话

背景永远不动，只有内容在动。翻走的那页不往旁边滑走，而是原地缩小、下沉、变虚，留在后面当新页面的背景。播放器是唯一的例外：它从下面升上来，往下一拉就收走。

## 2. 底色和主题

| | 浅色 | 深色 |
|---|---|---|
| 底色 `--bg` | `#f2f2f0` 浅白 | `#000000` 纯黑 |
| 墨色 `--fg` | `#111214` | `#f2f2f3` |
| 二级文字 `--fg2` | 墨色 62% | 墨色 64% |
| 三级文字、未选中图标 `--fg3` | 墨色 36% | 墨色 38% |
| 分隔线 `--hair` | 墨色 10% | 墨色 14% |
| 浅填充 `--fill` | 墨色 5% | 墨色 8% |
| 玻璃 `--glass` | 白 60% | `rgb(30 30 32)` 55% |
| 播放器面板 `--sheet` | `rgb(248 248 246)` 86% | `rgb(22 22 24)` 86% |
| 收藏的心 `--like` | `#f0467f` | `#ff6b9a` |

- 底色是一块纯色，页面自己没有底色，只有内容。
- 默认浅色。右上角圆钮切换，新主题从按钮处以圆形铺开（约 820ms）；不支持时全局颜色渐变 0.6s。
- 界面本身是单色的。唯一的颜色来自曲目：每首曲目有一个色相，封面、波形已播放部分、播放按钮、类型标签都用它，写成 `oklch(亮度 彩度 色相)`，浅色主题亮度 .52、彩度 .17，深色主题亮度 .82、彩度 .13。收藏的心是另一个固定的粉色。

## 3. 字体

- 字体栈：`"Jost", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。拉丁字母和数字用 Jost，中文落到系统字体。字体文件随应用打包，不依赖外部字体服务。
- 标题用 300 细体，正文用 400。

| 用途 | 字号 / 行高 | 字重 | 字距 |
|---|---|---|---|
| 页面大标题 | 36 / 42 | 300 | 1px |
| 曲目名、音乐人名（大） | 34 / 37 | 300 | 0.4px |
| 小节标题 | 12.5 / 16 | 400 | 2px |
| eyebrow 小标 | 11.5 / 15，全大写 | 400 | 1.6px |
| 列表行标题 | 16.5 / 21 | 400 | — |
| 列表行副标题、时长 | 13 / 18 | 400 | — |
| 正文 | 15 / 23 | 400 | — |
| 注释 | 12.5 / 19 | 400 | — |

- 数字一律 `tabular-nums`。
- 输入框字号 16，小于它 iPhone 聚焦时会自动放大。

## 4. 布局

- 内容列最宽 460px，居中；左右留白 20px（横屏时取安全区和 20px 的较大者）。
- 页面内各区块间距 28px，区块内标题到内容 12px。
- 页面内容一直铺到屏幕上下边缘，顶部清晰显示在状态栏下面，不做渐隐。需要避让的地方自己减安全区：页面上留白、返回钮、底栏、提示条。
- 没有标题栏。标题是内容最上方的大标题，跟着内容滚走。子页面左上角有一个悬浮的玻璃圆钮（42px）用来返回。
- 圆角：封面 14–20px，列表小封面 11px，播放器面板顶部 28px，按钮和标签全圆。
- 卡片样式几乎不用：列表行没有底色，只有一条分隔线。玻璃只用在浮起来的东西上（返回钮、主题钮、播放条、播放器面板）。

## 5. 景深翻页

页面栈里每个新页都是一个横向的原生滚动手势，向右滑返回。

| 参数 | 值 | 说明 |
|---|---|---|
| 进入时长 | 660ms | 缓动 `cubic-bezier(.2,.86,.24,1)` |
| 进入位移 | 整页从右侧约 17% 屏宽处滑入 | 用库的 `enter()`，是动画不是滚动 |
| 内容错开 | 每块延迟 20ms，最多 7 档 | 各块再从右 28px、透明度 0 进来 |
| 后面那页（第 1 层） | 缩到 0.86，下沉 4.5%，模糊 20px，透明度 0.5 | |
| 再后面（第 2 层） | 缩到 0.74，下沉 10%，模糊 40px，透明度 0 | |
| 更深的层 | 不渲染 | `visibility: hidden` |
| 返回的提交点 | 屏幕右侧外 10% | 库的 `overshoot: 0.1` |
| 滑走的内容淡出 | 移动到 80% 屏宽时完全透明 | |
| 末段穿透 | 内容透明之后不再接触摸 | 下面那页可以立刻操作 |

- 返回时后面两层的缩放、下沉、模糊、透明度，以及顶页内容的淡出，全部绑在顶页的滚动时间线上，每帧不跑 JS。
- 进入期间不挡触摸：手指可以直接上下滚新页；点按和返回手势等页面到位。
- 每个页面至少能滚 1px，并且把回弹留在自己身上，短页面不会把拖动传给整页。

## 6. 播放器

- 任何时候都从下面升上来，盖住包括底栏在内的一切；往下拉收走。点列表里的任意曲目、点播放条，都是打开它。
- 它是一个纵向的原生滚动手势：跟手、惯性、吸附都是浏览器的。升起用 `enter()`，620ms。
- 面板：顶部离状态栏 12px，上圆角 28px，玻璃底，顶上有一条 38×5 的抓手。
- 面板里的内容自己滚动；滚到顶之后再往下拉，拉动的就是面板本身。
- 面板后面的整个界面缩到 0.92、下沉 1.2%、模糊 14px、透明度 0.45，同样绑在面板的滚动时间线上，往下拉时跟着回到焦点。
- 在播放器里点相似曲目：原地换歌。点音乐人或标签：面板先收走，再在下面的页签里打开对应页面。

## 7. 底栏（DotTabBar）

以后常用的底栏，封装在 `app/src/ui/DotTabBar.web.jsx`，自带样式，单文件加 `glider.js`、`platform.js` 即可搬走。

- 只有图标，没有文字。当前页签的图标是墨色，其余是三级灰；当前图标下方有一个 6px 的圆点。
- 高 52px。图标 25px，在这一行里垂直居中。
- 没有背景框、边框和阴影。图标后面有一条只做模糊的胶囊：中间约 44px 高的一条完全模糊（18px），向上下左右各用约 28px 渐渐变清晰，两端是半圆。底栏离屏幕底边至少 26px，模糊在到达底边之前已经完全清晰。
- 整条底栏是一个大的 `<label>`，里面包着隐藏的原生开关：iPhone 上手指点它会触发系统触感。安卓走震动接口，每经过一个页签震一下。
- 圆点就是滑块，由弹簧驱动，不用 CSS 过渡，所以不会瞬移：
  - 点按：弹到点中的页签。
  - 按住拖动：跟着手指走，经过哪个页签就切到哪个；松手弹回到位。
  - 按住时被拉成扁椭圆（约 2.6 倍宽、0.76 倍高）；移动时按速度沿路径拉长压扁。
  - 弹簧参数：按住时刚度 520、阻尼 38；松手后刚度 300、阻尼 22，带一点回弹。
- 再点一次当前页签：回到该页签的第一页；已经在第一页就滚回顶部。
- 切换页签时内容淡入淡出 0.28s，离开的那一页同时缩到 0.96 并模糊 12px。

用法：

```jsx
<DotTabBar
  tabs={[{ key: 'home', label: '发现', icon: <Icon name="compass" size={25} /> }, …]}
  index={tab}
  onChange={(i) => setTab(i)}
  onReselect={(i) => popToRoot(i)}
/>
```

颜色可以用 CSS 变量覆盖：`--dtb-fg`、`--dtb-muted`、`--dtb-blur`。

## 8. 列表行

- 从左到右：52px 封面、曲名加「音乐人 · 类型」、时长、一个心。
- 心是空心的三级灰；收藏后变成实心粉色。
- 不显示波形和 BPM，这些只在播放器里。
- 点行的任意位置：播放这首并升起播放器。点心：收藏或取消，不打开播放器。
- 正在播放的那一行，曲名用这首曲目的颜色。

## 9. 触感

- 所有按钮都是 `<label>` 包隐藏开关的写法（`Tap` 组件）；开关只在 iPhone 上渲染，不设 tabindex。
- iPhone 网页一次点按只能震一下，拖动途中不能震。

## 10. 技术结构

React Native 写法，网页端用 react-native-web 渲染。页面内容用 `View`、`Text`、`Pressable`、`Image`、`TextInput`；手势、模糊、滚动时间线这些只有网页有的部分放在 `.web.jsx` 文件里，和 scroll-gesture 库的做法一致。

| 路径 | 内容 |
|---|---|
| `app/src/lib/scroll-gesture.js` | 手势核心（从 swipe 仓库复制） |
| `app/src/lib/depth-stack.js` | 景深页面栈，不依赖框架 |
| `app/src/nav/DepthStackView.web.jsx` | 页面栈的 React 封装，`useNav()` |
| `app/src/ui/DotTabBar.web.jsx` | 底栏组件 |
| `app/src/ui/glider.js` | 底栏和分段切换共用的弹簧滑块 |
| `app/src/ui/PlayerSheet.web.jsx` | 播放器面板 |
| `app/src/ui/Tap.jsx`、`parts.jsx` | 按钮、文字、列表行、标签等内容组件 |
| `app/src/screens/` | 各页面 |
| `app/src/styles.css` | 设计令牌、根布局、页面栈和面板的样式 |
| `public/` | 构建结果，仓库部署的就是它 |

构建：

```bash
cd depth-music/app
```

```bash
npm install
```

```bash
npm run build
```

## 11. 还没做的

- 没有 iOS / Android 原生端的实现：手势、模糊和滚动时间线目前只有网页版。
- 没有音频，播放进度是模拟的。
- 主屏幕模式下铺满整屏的问题在这台测试手机上没有解决，“我的”里保留了手动开关和屏幕数据。
