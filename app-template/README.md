# app-template

[APP-Template](https://github.com/gpt6astramax/APP-Template) 框架的示例应用的构建产物，用来在线试用。

- 这里只有 `public/`（`npm run build` 的 `dist/`），没有源码。源码和文档在 APP-Template 仓库。
- 同一份文件同时是网页、可安装的 PWA、以及 App 外壳（APP-Template 的 `shell/`）加载和热更新的来源。
- 更新：在 APP-Template 里 `npm run build`，把 `dist/` 的内容换到这里的 `public/`，推送。
